# [Remove Repeated Digits](https://www.geeksforgeeks.org/problems/remove-repeated-digits-in-a-given-number4014/1)
## Easy
Given a number n, remove consecutive repeated digits from it.
Examples:
Input: n = 1224
Output: 124
Explanation: Two consecutive occurrences of 2 have been reduced to one.

Input: n = 1242
Output: 1242
Explanation: No digit is repeating consecutively in n.

Constraints:1&lt;=n&lt;=1018
