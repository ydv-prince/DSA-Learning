# [Ugly Number II](https://www.geeksforgeeks.org/problems/ugly-number-ii/1)
## Medium
Given an integer n,&nbsp;&nbsp;return the nth&nbsp;ugly number.&nbsp;An&nbsp;ugly number&nbsp;is a positive integer whose prime factors are limited to 2, 3 and 5.Examples:Input: n = 5
Output: 5
Explanation: Ugly Numbers - 1, 2, 3, 4, 5, 6, 8, 9, 10, 12. So, 5th Ugly Number is 5Input: n = 10
Output: 12Explanation: 10th Ugly Number is 12
