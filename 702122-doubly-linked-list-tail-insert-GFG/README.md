# [Doubly Linked List Tail Insert](https://www.geeksforgeeks.org/problems/doubly-linked-list-tail-insert/1)
## Easy
Given a doubly linked list of size n, insert an element data after the tail. The driver code will print the LinkedList both forward and then backward to verify the result.
Examples:
Input:data = 8
Output: 1 2 3 4 5 8
8 5 4 3 2 1
Input:data = 89
Output: 2 4 6 7 5 1 10 8989 10 1 5 7 6 4 2
Constraints:1 ≤ number of nodes ≤ 10^3
