# [Deletion at the End of a Linked List](https://www.geeksforgeeks.org/problems/deletion-at-the-end-of-a-linked-list/1)
## Easy
Given a Linked List, delete the tail (i.e., the last node) of the Linked List and return the new head of the modified Linked List.Examples:Input: head[] = [1, 2, 3, 4, 5]Output: 1 -&gt; 2 -&gt; 3 -&gt; 4Explanation: After deleting tail from the given linked list, we'll be left with just 1 -&gt; 2 -&gt; 3 -&gt; 4.
Input: head[] = [3, 12, 15]Output: 3 -&gt; 12Explanation: After deleting tail from the given linked list, we'll be left with just 3 -&gt; 12.
